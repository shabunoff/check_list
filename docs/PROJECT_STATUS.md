# Project Status (Current)

Дата актуализации: 2026-03-11

## 1) Бизнес-логика
- Чек-листы создаются только вручную.
- Структура: `Checklist -> Section -> Item -> Field -> Option`.
- У пункта может быть любое количество полей.
- Типы полей: `text`, `number`, `select`.
- Полное удаление чек-листа доступно из `/checklists` (с подтверждением).

## 2) Аудиты
- У сотрудника может быть несколько аудитов.
- Ограничение: один аудит на пару `(executor, checklist)`.
- Статусы аудита: `draft`, `completed`.
- После завершения аудит можно редактировать.

## 3) Назначения на опрос
Реализована сущность `ChecklistAssignment`:
- `checklist`
- `executor`
- `manager`
- `audit` (опционально)
- `status` (`assigned`, `in_progress`, `completed`)
- `created_at`

Правила:
- одно назначение на пару `(checklist, executor)`.
- при старте аудита из назначения создается/открывается аудит.
- при смене статуса аудита синхронизируется статус назначения.

## 4) Роли и доступ
- `leader`:
  - управление чек-листами и конструктором;
  - массовые назначения сотрудников на опрос;
  - экспорты, включая `/checklists/<id>/export-min` и `/checklists/<id>/export-answers`;
  - массовые операции по сотрудникам;
  - удаление чек-листов.
- `manager`:
  - просмотр назначенных чек-листов (`/survey`);
  - работа в `/checklists/<id>/survey` только по своим назначениям;
  - запуск/заполнение аудита.
  - при открытии `/checklists` выполняется редирект в `/survey` (без 403).

## 5) Массовое назначение
На `/checklists/<id>` (leader):
- выбор менеджера;
- чекбоксы сотрудников;
- `Выбрать всех`;
- `Снять все`;
- возможность выбрать всех и снять часть вручную;
- кнопка `Назначить выбранных`.

## 6) Страница опроса по чек-листу
`/checklists/<id>/survey`:
- таблица назначенных сотрудников;
- фильтры:
  - по сотруднику (`icontains` по ФИО);
  - по статусу аудита (`Все`, `Не создан`, `Черновик`, `Завершен`);
- переименована колонка `Аудит` -> `Статус`;
- кнопки действий:
  - `Начать` (если аудита нет),
  - `Открыть` (если аудит `draft`),
  - `Изменить` (если аудит `completed`).

## 7) Основные страницы
- `/login`
- `/executors`
- `/executors/<id>`
- `/audit/<id>`
- `/checklists`
- `/checklists/<id>`
- `/checklists/<id>/survey`
- `/survey`
- `/reports`
- `/admin`

## 8) Экспорт
- Общие: `/reports/export/matrix`, `/reports/export/rows`
- По чек-листу:
  - `/checklists/<id>/export-min`
  - `/checklists/<id>/export-answers`

## 9) UI и дизайн
- Bootstrap 5 + кастомные акцентные классы кнопок:
  - `btn-accent` (красная заливка)
  - `btn-accent-outline` (красный контур)
- На странице `/checklists` карточки переведены на адаптивную сетку без «плавающей» верстки.

## 10) Ограничения
- Импорт чек-листов отключен (только ручное создание).
- Полное удаление сотрудников и чек-листов необратимо.
- Автотесты отсутствуют.
