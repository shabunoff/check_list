# Project Status (Current)

Дата актуализации: 2026-03-11

## 1) Бизнес-логика
- Чек-листы создаются только вручную.
- Структура: `Checklist -> Section -> Item -> Field -> Option`.
- У пункта может быть любое количество полей.
- Типы полей: `text`, `number`, `select`.
- Полное удаление чек-листа доступно из `/checklists` (с подтверждением).

## 2) Термины (обновлено)
- Сущность `Executor` в интерфейсе называется **Респондент**.
- Поле `city` в интерфейсе называется **Группа**.
- Технические имена в БД/коде (`executor`, `city`) оставлены без изменений.

## 3) Аудиты
- У респондента может быть несколько аудитов.
- Ограничение: один аудит на пару `(executor, checklist)`.
- Статусы аудита: `draft`, `completed`.
- После завершения аудит можно редактировать.

## 4) Назначения на опрос
Реализована сущность `ChecklistAssignment`:
- `checklist`
- `executor`
- `manager`
- `audit` (опционально)
- `status` (`assigned`, `in_progress`, `completed`)
- `created_at`

Правила:
- одно назначение на пару `(checklist, executor)`;
- при старте аудита из назначения создается/открывается аудит;
- при смене статуса аудита синхронизируется статус назначения.

## 5) Роли и доступ
- `leader`:
  - управление чек-листами и конструктором;
  - массовые назначения респондентов на опрос;
  - экспорты, включая `/checklists/<id>/export-min` и `/checklists/<id>/export-answers`;
  - массовые операции по респондентам;
  - удаление чек-листов.
- `manager`:
  - просмотр назначенных чек-листов (`/survey`);
  - работа в `/checklists/<id>/survey` только по своим назначениям;
  - запуск/заполнение аудита.
  - при открытии `/checklists` выполняется редирект в `/survey` (без 403).

## 6) Страница `/checklists`
- Адаптивные карточки чек-листов.
- Динамика по назначениям:
  - `Назначено`
  - `Завершено (N%)`
  - `Черновиков (N%)`
  - `Не начато (N%)`
- Полоска прогресса по статусам.
- Кнопка полного удаления чек-листа.

## 7) Страница опроса по чек-листу
`/checklists/<id>/survey`:
- таблица назначенных респондентов;
- фильтры:
  - по респонденту (`icontains` по ФИО);
  - по статусу аудита (`Все`, `Не создан`, `Черновик`, `Завершен`);
- колонка `Статус` (вместо `Аудит`);
- кнопки действий:
  - `Начать` (если аудита нет),
  - `Открыть` (если аудит `draft`),
  - `Изменить` (если аудит `completed`).
