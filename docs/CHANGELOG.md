# Changelog

Все заметные изменения проекта в хронологическом порядке.

## 2026-03-05
### Added
- Создан новый Django-проект `audit_project`.
- Базовые страницы, модели и импорт сотрудников.
- Первичная версия чек-листов и экспортов.

## 2026-03-06
### Added
- Массовая деактивация и полное удаление сотрудников.
- Ручной конструктор чек-листов с динамическими полями.
- Переход на универсальные значения аудита по полям.

### Changed
- Импорт чек-листов отключен.

## 2026-03-11
### Added
- Модель `ChecklistAssignment` (назначения на опрос).
- Страницы:
  - `/survey`
  - `/checklists/<id>/survey`
  - `/checklists/<id>/export-min`
- Назначение сотрудников на чек-лист с выбором менеджера.
- Синхронизация статуса назначения со статусом аудита.
- Массовое назначение сотрудников в `/checklists/<id>`:
  - чекбоксы;
  - `Выбрать всех`;
  - `Снять все`;
  - выбор всех с возможностью снять отдельных.
- Для `manager` доступ к `/checklists` изменен на редирект в `/survey` вместо `403`.
- Страница `/checklists/<id>/survey` получила фильтры:
  - по сотруднику/респонденту (ФИО, partial match);
  - по статусу аудита (`Не создан`, `Черновик`, `Завершен`).
- На `/checklists` добавлено полное удаление чек-листа кнопкой `Удалить` с подтверждением.
- На `/checklists` добавлена динамика по назначениям:
  - `Назначено`
  - `Завершено` / `Черновиков` / `Не начато` с процентами.
  - визуальный progress-bar.
- Ребрендинг интерфейса на `CheckList+`.
- Добавлены бренд-ассеты:
  - `static/img/logo2.svg`
  - `static/img/favicon.svg`.
- Добавлен футтер с разработчиком и ссылкой: `Shabunoff Systems Lab` / `https://shabunoff.ru/`.

### Changed
- Снят лимит одного аудита на сотрудника.
- Добавлена уникальность аудита по паре `(executor, checklist)`.
- Карточка сотрудника обновлена: список аудитов и создание нового по доступным чек-листам.
- Matrix-экспорт адаптирован под несколько аудитов сотрудника.
- На `/checklists/<id>/survey`:
  - колонка `Аудит` переименована в `Статус`;
  - кнопки действий переименованы в `Начать` / `Открыть` / `Изменить`.
- В базовой теме добавлены кнопочные стили `btn-accent`, `btn-accent-outline`, `btn-neutral`.
- На `/checklists` исправлены артефакты разметки (убраны literal-символы `` `r`n ``).
- На `/checklists` переработана адаптивная верстка карточек.
- Термины в UI и экспорте изменены:
  - `Сотрудник` -> `Респондент`
  - `Город` -> `Группа`.
- `STATIC_URL` изменен на `/static/`.
- Добавлен `STATICFILES_DIRS = [BASE_DIR / 'static']`.
- Для всех текущих респондентов массово проставлена группа `Дезинфектор`.
